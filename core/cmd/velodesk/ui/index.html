Senha para acesso sem supervisão

Quem tiver essa senha controla este computador sem precisar de confirmação. Não use em computadores de bancos, pagamentos ou dados sensíveis.
Mantenha a senha em sigilo e não a compartilhe.
Para mais segurança, ative a autenticação de dois fatores e a lista de IDs permitidos em Configurações › Acesso.

Ativar autenticação de dois fatores

1. Abra um app autenticador (Google Authenticator, Microsoft Authenticator, Aegis…).
2. Escaneie o QR code ou digite a chave.
3. Digite o código de 6 dígitos que o app mostrar.
